# Ammar Yasser — Portfolio

[View portfolio](https://ammaryasser455.github.io/)

My GIS developer portfolio, built with React, TypeScript and Vite. Features an interactive 3D character, a GIS project atlas, a scroll-linked Moon and chess, with a dark purple theme.

## Edit content

- Profile and links: `src/data/site.ts`
- Biography: `src/data/about.ts`
- Projects: `src/data/projects.ts`
- Project images: `src/data/projectMedia.ts` and `public/images/projects/`
- Experience: `src/App.tsx`
- Tech stack: `src/TechStack.tsx`
- Chess profile: `src/ChessPage.tsx`
- Styling: `src/additions.css`
